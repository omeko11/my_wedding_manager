================================================================================
PETUNJUK DATABASE LOKAL & BACKUP DATA - MY WEDDING MANAGER
================================================================================

Seluruh data dari Google Spreadsheet ("DB Wedding" - Tasks, Guests, Settings)
SUDAH DI-BACKUP PERMANEN ke Database Lokal di dalam folder project ini:

1. "database/wedding_db.json"  : File Database Lokal Utama (Aktif dibaca & ditulis langsung oleh aplikasi)
2. "database/init.sql"         : Struktur Tabel & Data SQL lengkap hasil backup Spreadsheet
3. ".data/wedding_db.json"     : Mirror runtime Database Lokal Next.js
4. "data_aplikasi/backups/"    : Pusat arsip backup Database Lokal:
   - wedding_db_terbaru.json         (Database JSON terbaru otomatis ter-update)
   - wedding_db_backup.json          (Master backup JSON dari Google Spreadsheet)
   - wedding_initial_seed.sql        (Master backup SQL dari Google Spreadsheet)
   - spreadsheet_tasks_backup.csv    (Backup mentah CSV sheet Tasks - 42 tugas)
   - spreadsheet_guests_backup.csv   (Backup mentah CSV sheet Guests - VIP Polri)
   - spreadsheet_settings_backup.csv (Backup mentah CSV sheet Settings - Biston & Pemberkatan)

--------------------------------------------------------------------------------
CARA BACKUP & RESTORE DATABASE LOKAL (SAMA SEPERTI WIRA SATYA 96):
--------------------------------------------------------------------------------

A. CARA BACKUP MANUAL KAPAN SAJA:
   1. Buka folder "data_aplikasi"
   2. Klik 2x file: "backup_sekarang.bat"
   -> Otomatis menyalin database lokal terbaru ke folder "data_aplikasi/backups/"
      lengkap dengan timestamp tanggal & jam.

B. CARA RESTORE / PULIHKAN DATA:
   1. Buka folder "data_aplikasi"
   2. Klik 2x file: "restore_data.bat"
   -> Otomatis memulihkan data dari "data_aplikasi/backups/" ke "database/wedding_db.json"
      dan ".data/wedding_db.json".
